# 5주차 과제 1: 기업 AI 및 데이터 보안 (하드코딩 키 리팩터링

1. 무엇이 위험했는지?
레거시 스크립트('legacy_report.py') 내부에 API 키와 데이터베이스 접근 정보가 평문으로 하드코딩되어 있어, 소스코드가 외부 저장소 등에 유출될 경우 시스템 전체 권한이 탈취당할 심각한 보안 위험이 있었습니다.

2. 어떻게 고쳤는지?
민감한 설정 값들을 '.env' 파일로 분리하고 'python-dotenv' 라이브러리를 통해 동적으로 로드하도록 코드를 수정하였습니다. 또한 '.gitignore'에 '.env'를 등록하여 버전 관리 추적을 원천 차단했습니다.

3. 실키 노출 시 올바른 대응 절차
만약 실제 서비스 운영용 키가 1차 커밋으로 노출되었다면, 
(1) 즉시 해당 API 키를 폐기 및 재발급
(2) Git 히스토리에서 민감 파일을 완전히 삭제한 뒤,
(3) 퍼블릭 저장소 로그를 검증하여 유출 여부를 확인해야 합니다.
